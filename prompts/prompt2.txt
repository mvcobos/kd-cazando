3. PROMPT MEJORADO
Quiero que rediseñes visualmente mi juego web para que tenga una
apariencia mucho más profesional, moderna, bonita y pulida, pero sin
que se vea sobrecargada.

IMPORTANTE:
- Puedes modificar el archivo HTML y el archivo CSS.
- Si es estrictamente necesario, puedes hacer pequeños ajustes
  estructurales en el HTML para mejorar el diseño.
- NO MODIFIQUES EL ARCHIVO JS BAJO NINGUNA CIRCUNSTANCIA.
- No cambies nombres de variables, funciones, IDs, clases o elementos
  que el JavaScript necesite para funcionar.
- No cambies la lógica, mecánicas, controles, posiciones funcionales
  ni comportamiento del juego.
- El resultado debe seguir funcionando exactamente igual que antes.
- Si necesitas agregar clases CSS al HTML para aplicar estilos,
  puedes hacerlo siempre que no interfiera con el JS.
- Conserva todos los elementos funcionales existentes.

OBJETIVO VISUAL:
Quiero que el juego tenga una estética inspirada en el océano, el mar
y las sirenas, pero de manera elegante y sutil. Debe transmitir:
- Frescura
- Limpieza
- Suavidad
- Un ambiente acuático
- Toques de fantasía tipo sirena
- Diseño moderno de videojuego casual
- Apariencia profesional y cuidada

PALETA DE COLORES OBLIGATORIA:
- #FFF9D2
- #FFEBCC
- #BFDDF0
- #8CC0EB
- #D8FFC5
- #C4F7CA

Usa estos colores como base principal. Puedes utilizar transparencias
y variaciones de luminosidad de estos mismos colores cuando sea
necesario, pero evita introducir colores que rompan la armonía de la
paleta.

ESTILO:
Quiero un diseño tipo "ocean fantasy / soft mermaid", no infantil
excesivamente caricaturesco.

Puedes utilizar de forma equilibrada:
- Gradientes suaves
- Sombras elegantes
- Iluminación ambiental
- Efectos de glow muy sutiles
- Difuminados
- Transparencias
- Efecto glassmorphism cuando tenga sentido
- Bordes redondeados
- Sombras internas
- Sombras externas
- Efectos de profundidad
- Brillos suaves
- Gradientes radiales
- Texturas marmoleadas o similares a ondas de agua
- Efectos que recuerden a reflejos de luz sobre el agua
- Pequeñas burbujas o elementos decorativos acuáticos únicamente si
  no interfieren con el juego

IMPORTANTE SOBRE LOS EFECTOS:
No quiero que uses todos los efectos indiscriminadamente. Combínalos
con criterio. La interfaz debe verse profesional y limpia, no como
una demostración de CSS. Evita exceso de glow, exceso de gradientes,
demasiadas sombras o demasiados elementos decorativos.

COMPOSICIÓN:
- Haz que el área principal del juego sea el elemento visual
  protagonista.
- Dale al canvas/contenedor una apariencia más elegante, con
  profundidad y separación visual del fondo.
- Crea un fondo agradable relacionado con el océano, utilizando
  gradientes y/o efectos marmoleados suaves.
- Si existe un título, marcador, instrucciones o botones,
  rediseñalos para que formen parte de la misma identidad visual.
- Mantén una jerarquía visual clara.
- Aprovecha espacios, márgenes y padding correctamente.
- Evita que todo quede pegado a los bordes.
- El diseño debe sentirse equilibrado.

TIPOGRAFÍA:
Si ya existe una tipografía funcional, puedes mejorarla mediante CSS.
Si necesitas incorporar una fuente externa, utiliza una fuente
moderna, redondeada y elegante que combine con la temática marina,
pero no uses una fuente excesivamente infantil. La legibilidad tiene
prioridad.

INTERFAZ:
Si existen botones:
- Hazlos modernos y agradables.
- Usa estados hover y active.
- Incluye transiciones suaves.
- Puedes usar sombras y pequeños efectos de iluminación.
- No hagas animaciones exageradas.

Si existen paneles, tarjetas o marcadores:
- Dales profundidad.
- Usa transparencias y bordes suaves.
- Mantén una estética coherente con el océano.

RESPONSIVE:
Asegúrate de que el diseño se vea bien en:
- Computadora
- Laptop
- Tablet
- Pantallas pequeñas

No rompas el tamaño ni la funcionalidad del canvas.

CÓDIGO:
- Mantén el código CSS organizado y fácil de entender.
- Agrupa estilos relacionados.
- Usa variables CSS para la paleta de colores.
- Evita repetir innecesariamente los mismos valores.
- No utilices !important salvo que sea absolutamente necesario.
- No agregues librerías JavaScript.
- No agregues frameworks innecesarios.
- No modifiques el JS.
